CS/IT Capstone Project

Project Abstract & Design

The Blood Bank Availability Finder with GPS is a web-based application designed to provide quick and efficient access to blood availability information during medical emergencies. Traditional methods of searching for blood donors are often manual, time-consuming, and lack real-time coordination, which can lead to critical delays. This project aims to address these challenges by developing a centralized and data-driven system that integrates location-based services for improved accessibility.

The system is developed using a client-server architecture, where the frontend is implemented using HTML, CSS, and JavaScript to provide an interactive user interface, and the backend is developed using server-side technologies to handle application logic and data processing. A relational database management system (MySQL) is used to store and manage structured data including donor details, blood group availability, and hospital records.

A key feature of the system is the integration of the Geolocation API, which enables the application to fetch the user's current location in terms of latitude and longitude. Based on this information, the system identifies and displays nearby donors or hospitals matching the required blood group. This location-based filtering enhances the efficiency of search operations and significantly reduces response time during emergency situations.

The application includes modules such as user registration, donor management, blood availability tracking, and search functionality. Users can request blood, while donors and administrators can update availability dynamically. Basic authentication mechanisms are implemented to ensure secure and controlled access to the system.
